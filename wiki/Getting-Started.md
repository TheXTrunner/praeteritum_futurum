# Getting Started

## Requirements

- **Minecraft:** 1.21.1
- **NeoForge:** Latest recommended build

## Installation

1. Install [NeoForge](https://neoforged.net/) for Minecraft 1.21.1
2. Download the latest release JAR from [GitHub Releases](https://github.com/TheXTrunner/praeteritum_futurum/releases)
3. Place the JAR in your `mods/` folder
4. Launch the game

## What is Praeteritum Futurum?

Praeteritum Futurum lets you create customizable automation systems. Place a **Machine Framework** block, then configure each slot with modules to dictate what goes where and how items get processed. You can also build a redstone circuit inside a Redstone Module and use signals to control compatible modules or connect machines.

The mod also includes exploration elements. Discover **Ruined Outpost** structures scattered across the Overworld using the **Anomaly Compass**, and salvage rare materials using specialized tools.

## Machine Framework Basics

- **27-slot modular grid** - configure each slot with a different module
- **Modular design** - mix and match modules to create custom automation pipelines
- **Blueprint system** - copy configurations across machines; Survival pasting consumes the required modules and Redstone Module components, while Creative pasting is free
- **Public/Private toggle** - anti-grief protection that prevents other players from using or interacting with your machine
- **Data Cleaning recipe** - clears saved module or Blueprint data. Components inside a Redstone Module return to your inventory; any overflow drops nearby
- **Redstone Module** - build vanilla-inspired circuits in a 9-by-6 grid and connect them to machine modules or world redstone through I/O faces
