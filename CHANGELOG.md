# Changelog

All notable changes to Praeteritum Futurum will be documented in this file.

## [0.1.1] - 2025-XX-XX

### Added
- Machine Framework block entity with 27-slot modular grid
- Inventory Module for internal item storage
- IO Module with directional input/output configuration
- Filter Module with whitelist/blacklist mode
- Smelting, Stonecutter, Composter, and Grindstone processing modules
- Blueprint system for copying machine configurations
- Anomaly Compass for locating Ruined Outpost structures
- Salvage Cutter and Yool wrench tools
- Config-driven structure spawn rate
- IO transfer tick rate configuration
- Yool rotation toggle configuration

### Changed
- Improved code quality with named constants and proper imports
- Added packet validation with distance checks for security
- Enhanced CI/CD pipeline with build artifacts and automated releases
- Resolved license inconsistency (now MIT)

### Fixed
- Deprecated API usage in block rotation
- Inline developer comments cleaned up
